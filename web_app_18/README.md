## Setup

Run the following to start the project:

### Angular:

#### Local:
```shell
cd web_app_18
nvm install
nvm use
json-server --watch db/db.json
npm run start
```

> [!NOTE] 
> Navigate to http://localhost:4200, connect through google and start using the app
